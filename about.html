Grade Calculator

Written in Java for Eclipse, this program asks for the student's name and grades in class participation, guided explorations, quizzes, projects, and the final demonstration. It applies weights of 15%, 20%, 25%, 20%, and 20% to those categories, adds the weighted scores, and assigns a letter grade from the resulting course score.

Concert Ticket Pricing

This Java program asks the user to choose a concert section (Front, Center, Side, or Upper) and enter a row from 1 to 60. It accepts uppercase or lowercase section letters, rejects invalid sections or rows, and calculates the ticket price by row: $450 for rows 1-15, $300 for rows 16-30, and $200 for rows 31-60.
